# **Labs_Señales_y_Sistemas**

Aqui voy a listar los resultados que obtengamos de los laboratorios sobre señales y los sistemas que las aplican.

Todos los resultados vienen en formato .zip, por lo que si estas en windows necesitas winrar y en linux necesitas zip (para realizar el comando unzip) al menos que ya lo tengas y utilices la opcion grafica (click derecho -> Extraer).

Cada archivo .zip contiene las preguntas del laboratorio (en un archivo llamado [Ficha de actividad.md], asi como lo que van a preguntar en el informe, los archivos de resultados como graficas, numeros, tablas, etc...
